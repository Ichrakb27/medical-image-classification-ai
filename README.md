# medical-image-classification-ai

## Overview

Deep Learning application for breast cancer histopathological image classification.

The project uses Convolutional Neural Networks to classify IDC breast cancer images.

## Technologies

- Python
- TensorFlow / Keras
- PyTorch
- OpenCV
- Scikit-learn
- Streamlit

## Models

Implemented models:

- Custom CNN
- DenseNet121
- ResNet50V2

## Results

Custom CNN:
- Accuracy: 96.94%

Transfer Learning:
- DenseNet121
- ResNet50V2

## Features

✅ Image preprocessing  
✅ Deep Learning training  
✅ Model evaluation  
✅ Prediction interface using Streamlit
